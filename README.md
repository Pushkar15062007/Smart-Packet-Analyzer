# Smart Packet Analyzer

An AI Powered Smart Packet Analyzer built using Python, FastAPI, Scapy, HTML, CSS and JavaScript.

## Features

- Live Packet Capture
- Protocol Distribution
- Security Overview
- AI Threat Detection
- Risk Level Indicator
- Dark/Light Mode
- Interactive Dashboard
- FastAPI Backend
- Real-Time Charts

## Technologies

- Python
- FastAPI
- Scapy
- HTML
- CSS
- JavaScript
- Chart.js

## Installation

```bash
pip install -r requirements.txt
```

Run

```bash
python capture.py
```

Open

```
http://127.0.0.1:8000
```
